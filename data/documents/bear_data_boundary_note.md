# BEAR Data Boundary Note

Source type: project internal note.
Published at: 2026.
Category: data_boundary.

BEAR trajectories in this project are HVAC simulation trajectories and controllable proxy data. They should not be described as real data center production telemetry.

Optional fields such as PUE, humidity, IT load, and chiller-level power must be marked as optional derived or optional synthetic unless a reproducible mapping proves their source.
